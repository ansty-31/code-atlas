使用：

```sh
npm run typecheck
npm run test:unit
npm run build -- --src /path/to/project
ATLAS_SRC=/path/to/project node tools/test/runner.mjs --spec multilingual --shots
```

主题回归可加 `--spec theming`。Playwright 浏览器在非默认位置时需设置 `PLAYWRIGHT_BROWSERS_PATH`。

## 保留的边界

STM32 的 67 个诊断文件包含预处理宏、条件编译或编译器扩展；当前不执行宏展开，也不声称所有声明都已提取完整。AUV 与小型 C++ 用例无语法诊断，同样不代表所有动态/语义关系均已解析。

Java 用小型混合数据回归验证保留的提取与引用逻辑；原 Project Zomboid 完整数据集的历史浏览器套件未在本轮重跑。没有将依赖游戏数据的旧断言强行改成对新工程通过。
